# 되찾은 날 — 8월 15일 광복절

초등학교 **1~2학년**을 위한 광복절 계기교육 그림책 게임입니다.
그림책을 넘기듯 이야기를 듣고, 중간중간 그림 속에서 **빼앗긴 것을 찾아 누르면** 그림이 되찾은 모습으로 바뀝니다.

- 단일 HTML 파일 · 설치 없이 브라우저만 있으면 됩니다
- 모바일·태블릿·전자칠판 모두 대응
- 15~20분, 한 차시 분량

## 진행 순서

```
표지 → 이야기 → 우리 집 → 우리 학교 → 우리 마을 → 몰래 지킨 것 → 8월 15일 → 태극기 완성
```

각 구역마다 그림 속에서 다섯 군데를 찾습니다. 다 찾으면 그림이 **되찾은 그림**으로 바뀝니다.
마지막에는 태극(빨강·파랑)과 4괘(건·감·리·곤)를 순서대로 눌러 태극기를 완성합니다.

## 다루는 내용

| 구역 | 아이가 알게 되는 것 |
|---|---|
| 우리 집 | 이름을 마음대로 쓸 수 없었다 (창씨개명, 1940년 2월) |
| 우리 학교 | 우리말·우리글을 배울 수 없었다 (조선어 교육 금지, 1938년 4월) |
| 우리 마을 | 하고 싶은 말을 할 수 없었다 |
| 몰래 지킨 것 | 그래도 지켜 낸 사람들이 있었다 |
| 8월 15일 | 1945년 8월 15일, 나라를 되찾았다 |
| 태극기 | 태극과 4괘의 이름과 자리 |

광복 = "빛을 되찾다", 잃었던 국권의 회복 / 1945년 8월 15일 광복, 1948년 8월 15일 정부 수립,
1949년 국경일 지정 — 국가보훈부 나라사랑배움터 자료를 따랐습니다.

**표현 수위** — 저학년 대상이라 징용·폭력 묘사는 넣지 않았습니다.
"이름을 못 쓰게 함, 우리말을 못 쓰게 함, 물건을 가져감"까지만 다루고, 전체 톤은 되찾은 기쁨에 둡니다.

## 읽어주기 음성 교체하기

이야기 화면의 **다시 들려주기** 버튼은 기본적으로 브라우저 내장 음성으로 읽습니다.
성우 음성으로 바꾸려면 `assets/voice/` 에 아래 파일을 넣고, `index.html` 맨 위 `CONFIG.voiceReady` 를 `true` 로 바꾸면 됩니다.

```
story-01.mp3  아주 먼 옛날, 우리 마을에는 …
story-02.mp3  그러던 어느 날, 일본이 …
story-03.mp3  학교에서도 우리말을 …
story-04.mp3  마을도 조용해졌어요 …
story-05.mp3  그래도 포기하지 않은 사람들이 …
story-06.mp3  그렇게 아주 오랜 시간이 흘렀어요 …
story-08.mp3  우리나라가 다시 빛을 되찾았어요 …
```

## 만들 때 쓴 것

- 그림 13장: gpt-image-2 생성 (수채화 그림책 톤, 1400×933로 통일)
- 배경음악 4곡: OpenGameArt CC0 — 출처는 `assets/audio/CREDITS.txt`
- 태극기: 이미지가 아니라 SVG로 직접 그려 4괘 위치를 정확히 맞췄습니다

## 좌표 수정하기

핫스팟 위치를 고칠 때는 주소 뒤에 `?debug=1` 을 붙입니다.
빨간 테두리가 보이고, 그림 위를 드래그하면 좌표 JSON이 화면에 출력됩니다.
그대로 복사해 `index.html` 의 `CONFIG.scenes[].hazards` 에 붙여 넣으면 됩니다.
