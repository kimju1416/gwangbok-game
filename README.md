# 영이의 광복절 — 1910~1945, 35년의 이야기

초등학교 **1~2학년**을 위한 광복절 역사 학습 자료입니다.
**이야기가 본체이고, 게임은 이해를 돕는 장치**입니다. 8개 장을 따라가면 광복절이 어떤 날인지 알게 됩니다.

- 단일 HTML 파일 · 설치 없이 브라우저만 있으면 됩니다
- 모바일·태블릿·전자칠판 대응
- 15~20분, 한 차시 분량

## 아이가 배우는 사실

| 연도 | 내용 |
|---|---|
| 1910 | 일본에게 나라를 빼앗김 (국권 피탈) |
| 1919 | 3·1운동 — 유관순, 천안 아우내 장터 만세운동 |
| 1938 | 학교에서 조선어 교육·사용 금지 |
| 1940 | 창씨개명 — 이름을 일본식으로 |
| 1941 | 금속류회수령 — 무기(총알)를 만들려고 밥그릇·수저·학교 교문까지 공출 |
| 1945 | **8월 15일 광복** — 35년 만에 나라를 되찾음 |
| 1948 | 8월 15일 대한민국 정부 수립 |
| 1949 | 8월 15일이 국경일로 지정 |

광복 = "빛을 되찾다(光復)", 잃었던 국권의 회복.

**표현 수위** — 저학년 대상이라 징용·고문·폭력 묘사는 넣지 않았습니다.
"이름을 못 쓰게 함 / 우리말을 못 쓰게 함 / 물건을 걷어 감"까지만 다루고, 전체 흐름은 되찾은 기쁨으로 끝납니다.

## 읽어주기 음성 교체하기

이야기 화면의 🔊 버튼은 기본적으로 브라우저 내장 음성으로 읽습니다.
성우 음성으로 바꾸려면 `assets/voice/` 에 `{장id}-{페이지번호}.mp3` 를 넣고
`index.html` 의 `const VOICE_READY = false;` 를 `true` 로 바꾸면 됩니다.

```
open-0.mp3  open-1.mp3  home-0.mp3  school-0.mp3
people-0.mp3  day-0.mp3  make-0.mp3  raise-0.mp3  check-0.mp3
```

대본은 `index.html` 의 `CH[].pages[].lines` 에 있습니다.

## 좌표 수정하기
