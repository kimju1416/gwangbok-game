# 태극기를 되찾아라 — 8월 15일 광복절

초등학교 **1~2학년**을 위한 광복절 계기교육 게임입니다.
동화를 한 장면씩 보고, 스테이지마다 **다른 종류의 게임**을 풀어 빼앗긴 것을 되찾습니다.
마지막에는 태극기를 직접 그려서 게양대에 올립니다.

- 단일 HTML 파일 · 설치 없이 브라우저만 있으면 됩니다
- 모바일·태블릿·전자칠판 대응 (세로 화면 기준)
- 15~20분, 한 차시 분량

## 진행 순서

| # | 이야기 | 게임 | 배지 |
|---|---|---|---|
| 1 | 나라를 빼앗겼어요 | **숨은 것 찾기** — 사라진 것 5개 | 우리 집 |
| 2 | 우리말을 못 쓰게 했어요 | **우리말 고르기** — 2지선다 3문항 | 우리말 |
| 3 | 마을이 조용해졌어요 | **어떻게 할까요** — 상황 선택 2문항 | 우리 마을 |
| 4 | 밤마다 몰래 배웠어요 | **손전등 탐색** — 깜깜한 방을 문질러 3개 찾기 | 밤의 지킴이 |
| 5 | 1945년 8월 15일 | **순서 맞추기** — 그날 일어난 일 4카드 | 그날 |
| 6 | 태극기를 그려요 | **태극기 그리기** — 태극→건→감→리→곤 | 태극기 |
| 7 | 높이 올려요 | **태극기 게양** — 버튼을 눌러 끝까지 | 게양 |

하트 3개, 점수(만점 500점), 등급 S/A/B/C, 배지 7개.
끝나면 이름을 넣어 **상장 PNG**를 저장할 수 있습니다.

1949년 국경일 지정 — 국가보훈부 나라사랑배움터 자료를 따랐습니다.

**표현 수위** — 저학년 대상이라 징용·폭력 묘사는 넣지 않았습니다.
"이름을 못 쓰게 함, 우리말을 못 쓰게 함, 물건을 가져감"까지만 다루고, 전체 톤은 되찾은 기쁨에 둡니다.

## 읽어주기 음성 교체하기

이야기 화면의 🔊 버튼은 기본적으로 브라우저 내장 음성으로 읽습니다.
성우 음성으로 바꾸려면 `assets/voice/` 에 아래 파일을 넣고,
`index.html` 의 `const VOICE_READY = false;` 를 `true` 로 바꾸면 됩니다.

```
home.mp3  school.mp3  town.mp3  night.mp3  day.mp3  draw.mp3  raise.mp3
```

각 파일은 해당 스테이지의 이야기 문장을 이어서 읽은 것입니다(대본은 `index.html` 의 `ST[].story.lines`).

## 만들 때 쓴 것

- 그림 13장: gpt-image-2 생성 (수채화 그림책 톤, 1400×933로 통일)
- 배경음악 4곡: FreePD CC0 — 출처는 `assets/audio/CREDITS.txt`
- 태극기: 이미지가 아니라 SVG로 직접 그려 4괘 위치를 정확히 맞췄습니다

## 좌표 수정하기

찾기 스테이지의 위치를 고칠 때는 주소 뒤에 `?debug=1` 을 붙이면 빨간 테두리가 보입니다.
좌표는 `ST[].spots` 의 `x, y, w, h`(그림 원본 기준 %)입니다.
